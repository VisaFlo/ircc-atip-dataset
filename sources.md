# Sources & Verification

Every thread in this dataset comes from records released by Immigration, Refugees and
Citizenship Canada under the **Access to Information Act**, via informal re-requests of
completed ATIP packages. Anyone can obtain the same source PDFs, free:

1. Go to the Government of Canada's completed-ATI search: https://open.canada.ca/en/search/ati
2. Search a request number below → "Request a copy of records" → submit the informal request form ($0)
3. IRCC emails the released package (typically within days)
