# Roadmap

What's landing in this dataset, roughly in order. Watch the commit log: data updates
ship as they're ready, not on a schedule.

## Now (automatic, daily)
- **Remaining Reps Mailbox packages** — 7 more ATIP packages ingesting toward full
  2016–2025 coverage (~5,000+ threads expected). Each lands as a `data:` commit.
- **New manuals from received packages** — R10 / CIO-Sydney intake manuals, latest
  Chinook training materials, APR portal statistics, eServices post-incident reports
  are received and queued for OCR.

## Next
- **GCMS codes reference** — the full GCMS coding manual (2A-2021-12699, ~3,570 pages)
  structured into a searchable code table. The abbreviations in every GCMS notes dump,
  finally decodable.
- **Webform / Client Support response templates** (2A-2020-81546) — the standard
  paragraphs IRCC staff use when answering applicants.
- **Functional Guidance repository** (2A-2019-16114) — internal interpretive guidance
  issued to officers.
- **Thread enrichment** — category and topic tags on mailbox threads.

## Under editorial review
- **Police certificate country matrix** — how to obtain a police certificate in 220+
  countries, with official links.
- **Program document checklists** — structured document requirements per immigration
  program, from official IRCC sources.

## Product
- **Search inside [VisaFlo](https://vflo.app)** — the practitioner's assistant answers
  "what did IRCC say about X" with sourced threads from this dataset, in the context of
  your own cases.

## Standing
- **New ATIP releases monitoring** — as IRCC completes new relevant Access to Information
  requests, we re-request and ingest them. If you know a completed IRCC ATIP request that
  belongs here, open an issue with the request number.
